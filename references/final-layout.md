## 3. 「一题一页」的实现：表格包题

```python
box = doc.add_table(rows=1, cols=1)      # 整题塞进一个单元格
table_borders(box, sz=0)                 # 无框
trPr = box.rows[0]._tr.get_or_add_trPr()
trPr.insert(0, OxmlElement('w:cantSplit'))   # 行不可分割 → 整题整体搬家
c = box.cell(0, 0)
# 之后所有 para / table 都 add 到 c 里
```

**为什么不用分页符**：分页符会造成半页空白，且题短时浪费。
**为什么不用 keepNext 链**：链太长（整题 > 一页）Word 照样断，还会把题头丢在页尾当孤行——实测出现过「p2 只有题头、p3 才是正文」。

## 4. 图能放多大：实测反解

```
content_cm = (页内最后一段 y − 页内第一段 y) / 28.3465 + 0.45
text_cm    = content_cm − 6.0 − 0.45            # 扣掉校准图 + 图注
cap_cm     = clamp(6.0, 16.0, 26.4 − text_cm − 0.85)
```

实测样本（13 题，单位 cm）：

| 题 | content | text | cap |
|---|---|---|---|
| 1 河豚 | 16.84 | 10.39 | 15.16 → 实取 14.2 |
| 2 大怪鱼 | 15.88 | 9.43 | 16.00 |
| 7 典例2 | 13.81 | 7.36 | 16.00 |
| 13 蚊子 | 18.32 | 11.87 | 13.68 → 实取 12.2 |

cap 之后再被「列宽 11.2cm / 高度 16cm」二次夹住，所以竖长的 989×1769 图实际是 **8.8 × 14.2**，横图铺满 **11.0 × 6.9**。

> 取整往下留 1cm 余量，是为了吸收「末行行高补偿」的误差——第一次按 15.16 取数就溢出了 1 页。

## 5. 整页长截图 → 图版页

一张真实案例：`image6.jpg = 989 × 3500`，是**同一页被手机截成 3 段**的复合图（`h/w = 3.54`）。

- 只贴第一段 → 用户直接反馈「原题截图显示不全」；
- 整页等比缩到 26.4cm 高 → 只有 7.4cm 宽，正文约 4pt，等于看不清；
- **定稿做法**：单独一页，切成两栏（切在最空白行，本例第 1403 行、墨迹 0%），每栏 8.4cm 宽、高 11.9 / 17.8cm；文字页末尾加 `▸ 卷面原图见下页`。

判定阈值：`h / w > 2.2` 走图版页。

## 6. 四轮返工记录（都是用户真实反馈）

| 轮次 | 用户要求 | 落地 |

| 1 | 重新排版成康奈尔错题集 | 31 页：封面 + 编排说明 + 索引 + 13 题 + 错因归纳 + 14 页附录 |

| 3 | 不要封面/纲要/编排说明/线索栏/总结栏/错因归纳/核心问题/学习建议 | 13 页，单栏，只留题头+①+②+③+订正区 |
| 4 | 再去掉星标·日期·页码·出处、错因、订正区，重排版面 | 13 页，连续流式，题装 cantSplit 单元，页眉代标题 |

结论沉淀：**默认就该是「题头 + ① + ②(右并图) + ③」；任何额外的栏、区、附录最后都会被删掉**。
