# 版式规格（layout-spec）

> ⚠️ **默认版式已改为「最终版式」：见 `final-layout.md`。**
> 本文描述的是**康奈尔三栏（线索栏 4.6 + 主笔记 + 总结栏）**的备选样式——用户实际会把它删到只剩「题头 + ① 原题 + ② 解题过程(右并截图) + ③ 答案」。只在明确要求「保留线索栏/总结栏」时才用本文件。

所有数值单位是厘米（cm），与 `assets/build_docx.py` 里的常量一一对应。改版式先改这里、再改代码，别反过来。

## 1. 页面几何

| 项 | 值 | 说明 |
|---|---|---|
| 纸张 | A4 21 × 29.7 | 竖排 |
| 左右边距 | 1.8 / 1.8 | 正文宽 **17.4** |
| 上下边距 | 1.55 / 1.35 | 正文高 **26.8**（一页的硬预算） |
| 页眉 / 页脚距边 | 0.78 / 0.68 | 页眉左标题 + 右副题，页脚居中 `— PAGE —` |
| 首页奇偶 | 不做区分 | `different_first_page = False`，首页也有页眉页码 |

**26.8cm 是唯一预算**：题头 + 题目 + 截图 + 解析 + 答案的合计超过它就换页，这是"一题一页"的判定线。

## 2. 配色

| 用途 | 变量 | 值 | 用在哪 |
|---|---|---|---|
| 正文 | `INK` | `#22303A` | 题干、解析 |
| 次要 | `MUTED` | `#6B7C88` | 来源标注、图注、页眉 |
| 主色 | `ACCENT` / `ACCENT_HEX` / `ACCENT_L` | `#1F5C74` / `1F5C74` / `#E9F2F6` | 序号、分区标签、题头底色、分隔线 |
| 暖色 | `WARM` / `WARM_HEX` / `WARM_L` | `#A55525` / `A55525` / `#FBF2E9` | 答案区标签、答案区底色、上边线 |
| 线 | `LINE_HEX` / `SOFT_HEX` | `#C9D6DE` / `#E3EAEE` | 卡片外框 / 表内细线 |

同一份文档只用这一套。加大类颜色（比如按学科分色）时，只替换 `ACCENT*`，`WARM*` 留给答案区。

| 题头标题 | 12.5 | 同上，加粗 |
| 题头右侧（来源·题型） | 9 | 同上，灰色 |
| 分区标签（主笔记区 / 答案区） | 8~8.5 | 微软雅黑，加粗，小字距 |
| 【题目】/【解析】 | 9.5 | 微软雅黑，加粗，主色 |
| 题干正文 | 10.2 | 宋体 / Times New Roman |
| 小问、选项、深缩 | 9.8 / 9.8 / 9.2 | 同上 |

行距：正文 1.30，列表 1.26，标签 1.05；段后距 1.2~2.2pt（都随 `fs` 缩放）。

## 4. 单题结构

```
表 A：3 行 × 1 列（整张卡片）
┌─ 行0 题头 ────────────────────────────────┐  底 #E9F2F6 + 下边线 1.5pt 主色
│ 01　河豚检索表与动物分类      第 7 题 · 选择题 │  序号 16pt + 标题 12.5pt + 右对齐来源
├─ 行1 主笔记区 ────────────────────────────┤  标签「主笔记区  NOTES」
│ 【题目】题干 / 小问 / 选项                  │  通栏 17.4
│ （可选）表格：检索表 / 数据表                │  嵌套表 B
│ （二选一）                                  │
│   · 通栏截图：1×1 边框表 + 图 + 图注          │  嵌套表 C，宽 = 图宽 + 0.30
│   · 并列截图：1 行 × 2 列（解析 │ 截图）      │  嵌套表 D，左栏宽 + 右栏宽 = 17.04
│ 【解析】逐步推导                             │
├─ 行2 答案区 ──────────────────────────────┤  底 #FBF2E9 + 上边线 1.8pt 暖色
│ 答案区  ANSWER   （1）E　（2）②③⑤           │  只有答案，不写"关键句"
└──────────────────────────────────────────┘
```

要点：

- **题头行、答案区行加 `cantSplit`**，避免标题或答案被拆到两页；**主笔记区不加**——加了以后，超高的行会被整块推到下一页，页数会莫名涨好几页。
- 卡片外框四条边 0.5pt `LINE`，内部 `insideH` 0.5pt，`insideV` 不画。
- 嵌套表宽：笔记区可用宽度 = 17.4 − 左右单元格边距 0.36 = **17.04**。并列版式左右栏之和必须 ≤ 17.04。

## 5. 截图尺寸规则

| 版式 | 图宽 | 用途 |
|---|---|---|
| 通栏 | `min(11.9, 16.65, 图高上限 / 比例)` | 比例 < 0.9（横长条）的截图 |
| 并列 | 右栏宽 − 0.45（约 5.6~8.6） | 比例 ≥ 0.9（竖页/方形）且通栏后被压到 < 7cm 的截图 |

选择逻辑（实测而非拍脑袋）：

1. 先按通栏排，用 `fit.py` 收到一页；
2. 若某题通栏图上算出来的宽度 < 7cm（说明它是被"压高"的，不是被"压宽"的），改为并列；
3. 并列后该题会**变矮**（因为省掉了整条图带，而解析本身只有 4~7cm 高），额度可以拿去把截图栏放宽——`fit.py` 会在"一页放得下"的前提下自动把截图栏解到最宽（上限 9.0）。

横长条截图（比例 0.44~0.65）**必须**走通栏：放进 6cm 侧栏后高度只剩 2.9cm，字会缩到看不清。

## 6. 富文本标记（content.json 里用）

| 写法 | 效果 |
|---|---|
| `**文字**` | 加粗 |
| `V{#总}` | 下标（总） |
| `cm{^3}` | 上标（3） |
| `　` | 全角空格，用于选项之间、答案之间留白 |

别在文档里用 `✓ ✗ ▸ ①②` 之外的生僻符号：`✓ ✗` 在部分中文打印字库里缺字形，**统一替换成 `√ × ■ ▲ □`**（GBK 全覆盖）。`①②③` 是 GBK 内的，可以放心用。

## 7. 表格（`add_grid`）

`{"cap": "检索表（乙）", "header": [...], "widths": [...], "rows": [[...], ...]}`

- 无表头时 `header: null`，四列等宽检索表直接用 `widths`。
- 单元格最小行高 0.58（表头 0.60），字号 9，居中。
- 宽度和超过笔记区可用宽时会自动等比缩放。

## 8. 页面节奏

- 每题强制 `page_break_before`（首题除外），所以**总页数 = 题数**是硬验收指标。
- 只要有一题跨页（`p != pa`），说明预算超了，必须回到 `fit.py` 继续压，不要靠"调小页边距"糊过去——那会连带改掉全篇版心。
